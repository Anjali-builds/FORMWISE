# FORMWISE - UI/UX Design Education Platform
FORMWISE is a modern UI/UX design education website created to present a cohort-based learning program for aspiring designers. The website focuses on a clean, premium, and editorial visual experience while clearly communicating the program, learning approach, student outcomes, and course journey.

## 📚 Learning Experience

FORMWISE is designed around a practical and portfolio-focused learning experience.

The program focuses on:

- UI/UX fundamentals
- Figma and interface design
- Real-world interface design
- Design thinking and problem solving
- Weekly feedback and design critique
- Practical design projects
- Portfolio-ready case study development

## 🎯 Project Focus

This project combines UI/UX design, front-end development, and generative AI-assisted visual creation to build a modern digital experience for a UI/UX design education brand.

The goal was to create a website that feels professional, creative, easy to navigate, and aligned with a premium design-education brand.

## 🚀 Project Outcome

FORMWISE was developed as a complete website project combining design, content, visual direction, and front-end implementation into one cohesive digital experience.
